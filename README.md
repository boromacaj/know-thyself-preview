# know-thyself-preview

Automated, anonymised review builds of Know Thyself. Nothing is edited here by hand: a workflow in the private source repository
builds one commit in the public shape (real QA records replaced by made-up people, no source maps, no private datasets), proves
that with a privacy assertion, and publishes it to a folder per branch.

No source code and no history live here; each publish replaces the previous state.
